# Codex

Install the local `whatsapp-mcp` personal plugin from this project. It supplies the MCP connection and a skill that guides Codex to find a chat, retrieve only the relevant messages, and then analyze them.

Do not also add the standalone endpoint to the same Codex profile. The plugin is the single supported Codex integration.

Typical request:

> Liste minhas conversas do WhatsApp, encontre Mariane e resuma as 100 mensagens mais recentes.
